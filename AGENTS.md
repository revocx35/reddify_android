# AGENTS.md — Reddify Android

Native client for the Reddify server (github.com/revocx35/reddify). Read [ARCHITECTURE.md](ARCHITECTURE.md).

## Layout
| Path | What |
|---|---|
| `core/src/main/kotlin/.../core/` | `Models.kt` (mirror of the server's `shared/api.d.ts`), `ApiClient.kt`, `Authentik.kt` (shared file) |
| `app/src/main/java/.../data/` | `AppGraph`, `KeystoreBox`, `AuthentikSignIn`, `OfflineStore` |
| `app/src/main/java/.../playback/` | `PlaybackService` (Media3), `PlayerConnection`, `CastSupport`, `Media.kt` |
| `app/src/main/java/.../ui/` | Compose UI; `theme/Icons.kt` is GENERATED by the server repo's `scripts/gen-android-icons.py` |
| `app/src/test/` | Robolectric screenshot tests against a mock server (answers recorded from a real server) |

## Commands
```bash
./gradlew --max-workers=1 :core:test :app:testDebugUnitTest                                 # 6 + 2 tests
./gradlew --max-workers=1 :app:testDebugUnitTest -Proborazzi.test.record=true --rerun-tasks # screenshots in app/build/screens
./gradlew --max-workers=1 :app:assembleRelease
```
On shared build hosts cap Gradle (the owner's hosts: `heavy`). The release key is kept outside the repo (the owner's
notes say where); its properties file goes to `keystore.properties` here (never commit). Cert SHA-256
`06:B8:F8:F3:A4:E3:3B:BA:43:04:A6:30:CD:D8:26:9D:68:74:C1:63:80:C4:CA:FC:EC:38:5D:D1:0F:27:24:B9`. Bump
`versionCode`/`versionName` in `app/build.gradle.kts` for every release; attach the signed APK to a GitHub release
and copy it to the server repo's `web/public/reddify.apk` before building the server image.

## Conventions
- API change: server's `shared/api.d.ts` first, then `Models.kt` (every field defaulted, unknown keys ignored).
- Every web UI change in the server repo must reach this app in the same task.
- Colours only from `ui/theme/Theme.kt` (same tokens as the web `:root`).

## Never
- Allow cleartext or user CAs, log tokens, or send the token to another origin.
- Commit `keystore.properties`, `local.properties` or keys.

## Gotchas
- Robolectric gives Media3's MediaController a null ComponentName: `PlayerConnection` skips connecting there.
- The Cast route picker needs AppCompat (`MainActivity : AppCompatActivity`, theme `Theme.AppCompat.NoActionBar`).
- Not yet exercised on a real device/emulator (0.1.0): check playback, notification and casting on a phone.
